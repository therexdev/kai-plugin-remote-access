Connect a client

  1. Create a remote key and paste it into the client’s API key field.
  2. Choose an online privacy mode in Core, then start Remote Access.
  3. Copy the base URL and choose one of your available models.

The relay at koinosai.com receives client API keys, prompts and responses. Give keys only to trusted clients.

Text chat only. Up to 16,000 characters of conversation and 4,096 output tokens. Streaming clients receive the completed answer in an SSE response.

Existing API keys and address settings

Keep existing clients working

Old gateway keys remain saved. They gain remote access only after you explicitly allow them here. Removing their remote access preserves their original local gateway permissions.

Replace your remote address

Keep your existing relay identity by default. Replacing it stops access and makes old base URLs invalid; keys stay saved.
