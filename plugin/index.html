Network & privacy

          
Local-Only is the default: AI requests stay on this machine. Koinos Node and explicit wallet actions use the blockchain independently. Local-First and Network unlock the “Koinos Network” model — requests overflow to network providers through the scheduler.
            Network requests run on other people's computers: the provider serving your request can read what it contains — nothing is stored by the serving path, but treat anything sent off this machine as visible to that provider.

    Remote access
    
            
          
    
          
    Use your API from anywhere — a phone, a server, another computer. The app keeps an
            outbound connection to koinosai.com (nothing to install, no router setup) and your API key works
            at the address below. Requests are answered by this computer, so it works while the app is
            running. An API key is required — without one the switch refuses, so your API is never open to
            the internet. Heads up: remote traffic passes through koinosai.com on its way here.
