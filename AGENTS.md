This is a KAI Foundation native plugin. Its service owns API credentials, usage, local HTTP listener and remote relay; the UI remains sandboxed. Native execution is explicitly full computer access, not a security sandbox. Use documented public Foundation APIs only; no Core internal imports or feature-specific privilege exceptions. Remote callers may only list installed local models or perform bounded text inference/embeddings. Never expose Core routes, wallet operations, Brain, accounts, tools or plugin RPC through the remote server. Require API keys even on loopback, reject browser-origin requests, enforce request bounds and revoke active work on disable. No automatic migration from old account/token storage. Never commit publisher private keys. Run npm test and signed package verification before immutable publication.
